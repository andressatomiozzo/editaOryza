# 📌 EditaOryza

Site institucional desenvolvido para uma página web.

<br>

## 🚀 Tecnologias utilizadas

* HTML 5
* CSS 3 (modules)
* TypeScript 6
* React

<br>

## 👤 Como interagir com o projeto

Acesse o [Link](https://dogs-wine.vercel.app/)

<br>

## ⚙️ Como rodar o projeto

```bash
# Clonar o repositório
git clone https://github.com/andressatomiozzo/editaOryza.git

# Entrar na pasta
cd editaOryza

# Instalar dependências
npm install

# Rodar o projeto - frontend
npm run dev

# Em outro terminal, entrar na pasta
cd backend-formulario

# Rodar o projeto - backend
node server.js

```
